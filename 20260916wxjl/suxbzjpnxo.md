# 【科普】如何解决婴幼儿喂养困难

> 更新时间：2026-09-16 (UTC+8)

婴幼儿时期生长发育迅速，对能量和营养的需求较高。但是，此时期儿童消化系统发育尚不完善，易受喂养习惯不良、生理、环境、心理等多方面因素的影响，容易发生喂养困难，从而影响儿童生长发育。

**喂养困难对生长发育的影响**

✦

✦

✦

喂养困难会使机体能量摄入不足，影响大脑关键期发育，造成婴幼儿智力发育落后。此外，喂养困难儿童常因添加辅食困难、延迟，导致口腔运动功能障碍、咀嚼不良、口腔感统失调，造成婴幼儿语言发育障碍、口吃、构音障碍等。

**导致喂养困难的因素**

✦

✦

✦

引发因素有食物来源、品种搭配与制作不当，儿童不同气质特点，进食技能发育不良，器质性疾病，儿童与家长互动不良等。在排除器质性疾病情况下，喂养互动不良最为常见。

**如何防范孩子喂养困难**

✦

✦

✦

**让孩子有饥饿感**：想让孩子能好好吃饭，首先要让他有饥饿感，喂养时间碎片化，零食不离手，过度焦虑孩子的食量，孩子就不会觉得饥饿，两餐之间不要有零食及任何其他食物。

**多夸奖鼓励进食**：孩子吃饭不好，批评是无法改善的，食欲与情绪密切相关，批评让孩子情绪变差，进食欲望更加受损。

**良好的就餐氛围**：吃饭的氛围感很重要，孩子进食也需要同伴，大人进食时，可以让孩子在儿童餐椅中吃自己的辅食。

**制定吃饭规则**：儿童进餐时，避免进食时用电视、电话、玩具等方式分散儿童注意力，限制就餐时间（20-30分钟），提供与儿童年龄相符的食物种类及质地，给小婴儿逐渐引入新食物，有时新的食物引入需要8-15次，鼓励较大婴儿、幼儿自己进食，包括抓食，允许与儿童年龄相符的狼藉。

**良好的进食行为**：观察婴幼儿在进食过程中发出饥饿或饱腹信号来调整喂养行为，可以通过与婴幼儿谈论食物、模拟良好的饮食行为、进行互动小游戏以及口头鼓励等方式实现。而强迫喂养、固定婴幼儿的脑袋、威胁或婴幼儿等喂养行为是不被认可。

**进食技能的训练：**包括适当口腔刺激，增加口腔运动力量及协调性，此外，选择不同形状、大小的奶瓶或是杯子亦有利于不同进食能力儿童摄入液体食物。
